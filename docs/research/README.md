# docs/research

Research notes. Every source has an `S-xxxx` entry in `SOURCE_REGISTER.md`; every finding an `F-xxxx` entry in
`FINDINGS_LOG.md`.

* [`ROBLOX_API_FACTS.md`](ROBLOX_API_FACTS.md) — the Roblox engine facts the design rests on (HttpService limits,
  EditableImage, RemoteEvents, secrets), each with its evidence and confidence.
* [`FORUM_FINDINGS.md`](FORUM_FINDINGS.md) — what Reddit and the DevForum discuss about in-game screen sharing (17 Reddit
  threads, 33 DevForum topics, official announcements), what this project already does, what was added and what was
  rejected.
* [`EXISTING_PROJECTS.md`](EXISTING_PROJECTS.md) — source-level review of the public Roblox screen-sharing projects and
  what this project took from them (or deliberately did not).
